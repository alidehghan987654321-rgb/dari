# First message (خوشامد اول تماس)

این جمله را در ElevenLabs در فیلد **First message** بگذارید. دوزبانه است و هم هوش مصنوعی بودن و هم ضبط تماس را اعلام می‌کند (الزام شفافیت UK GDPR).

## نسخه پیش‌فرض (فارسی اول)

```
سلام، {{business_name}}، بفرمایید. من دستیار هوشمند هستم و تماس برای کیفیت ضبط می‌شه.
Hello, you're through to {{business_name}}. I'm the AI assistant, and this call is recorded. How can I help?
```

## نسخه کوتاه‌تر (برای کسب‌وکارهایی که بیشتر مشتری انگلیسی‌زبان دارند)

```
Hello, {{business_name}}, I'm the AI assistant and this call is recorded. سلام، فارسی هم صحبت می‌کنم. How can I help?
```

## نکته‌ها

- طول جمله اول کمتر از ۸ ثانیه باشد؛ مشتری‌ها منتظر نمی‌مانند.
- اسم کسب‌وکار را با **Pronunciation dictionary** در ElevenLabs درست کنید تا غلط تلفظ نشود.
- صدای انتخابی: یک صدای فارسی طبیعی از Voice Library یا کلون صدای خود صاحب کسب‌وکار (فقط با رضایت کتبی او).
