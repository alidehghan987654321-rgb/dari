# پرامپت‌های ساخت

هر فایل یک «تکلیف کامل» برای یک دستیار کدنویسی AI است (مثلاً Claude Code) یا برای یک برنامه‌نویس تیم.

## نحوه استفاده

1. ریپوی پروژه را باز کنید (همین پوشه `ai-receptionist`).
2. اول محتوای `00_master_context.md` را بدهید، بعد فایل ماژول.
3. یک ماژول در هر شاخه (branch) و هر PR. قبل از merge، چک‌لیست «Definition of done» در master context را تیک بزنید.
4. پرامپت‌ها انگلیسی‌اند چون دستیارهای کدنویسی با انگلیسی دقیق‌ترند؛ متن رابط کاربری فارسی است.
