# چک‌لیست راه‌اندازی مشتری جدید

زمان هدف: کمتر از ۲ ساعت کار ما برای هر مشتری.

## ۱. جمع‌آوری اطلاعات (جلسه ۳۰ دقیقه‌ای با صاحب کار)

- [ ] شرکت/کسب‌وکار ثبت‌شده در بریتانیا است (شماره Companies House یا مدرک ثبت sole trader) و مالک یا کنترل‌کننده‌اش شخص یا شرکتی داخل ایران نیست (به خاطر تحریم‌های بریتانیا؛ در صورت شک، قبل از قرارداد از وکیل بپرسید)

- [ ] اسم کسب‌وکار (املای انگلیسی و تلفظ درست فارسی)
- [ ] آدرس کامل، نزدیک‌ترین ایستگاه، وضعیت پارکینگ
- [ ] ساعات کاری هر روز + روزهای تعطیل سال
- [ ] لیست خدمات: اسم فارسی و انگلیسی، مدت، قیمت
- [ ] ظرفیت: چند نفر هم‌زمان کار می‌کنند
- [ ] حداقل فاصله رزرو (مثلاً ۱ ساعت قبل) و حداکثر روزهای جلوتر
- [ ] قوانین: لغو، تأخیر، پرداخت، بچه‌ها، walk-in
- [ ] ۵ تا ۱۰ سؤال پرتکرار مشتری‌ها و جوابشان
- [ ] شماره موبایل برای انتقال تماس + ساعاتی که انتقال مجاز است
- [ ] chat id تلگرام صاحب کار (برای خلاصه تماس‌ها)
- [ ] صدای دلخواه: زن یا مرد؛ یا کلون صدای خودش (فقط با رضایت کتبی)
- [ ] پیامک تأیید فارسی بفرستیم یا انگلیسی؟
