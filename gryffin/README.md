# سایت مادر گریفین (`gryffin.uk`)

صفحه‌ی اصلی شرکت. محصول‌های گریفین رو کنار هم معرفی می‌کنه و هر کدوم به **سایت خودش** لینک می‌شه.
هر محصول مستقل می‌مونه و کار خودش رو در سایت خودش انجام می‌ده:

| محصول | برای کیه | آدرس |
|---|---|---|
| شکارچی | فروشنده‌های راینومال که از چین وارد می‌کنن | `hunter.gryffin.uk` |
| Bookfin | سالن‌های زیبایی و آرایشگاه‌ها (نوبت‌دهی) | `bookfin.gryffin.uk/ir` |

این صفحه کاملاً ایستاست: یه `index.html`، یه `site.css`، فونت‌ها و لوگو. نه سرور داره، نه دیتابیس، نه
اسکریپت. فونت‌ها روی خود سایت میزبانی می‌شن (به گوگل وصل نمی‌شه) تا توی ایران هم سریع باز شه.

## اضافه‌کردن یا ویرایش محصول

توی `index.html` هر محصول یه `<article class="product">` داره. برای محصول جدید، یکی رو کپی کن و
اسم، «برای»، توضیح، آدرس و لینک دکمه رو عوض کن. عدد «2 محصول» بالای فهرست رو هم به‌روز کن.
لوگو رو بذار توی `img/`؛ اگه لوگو نداره، مثل Bookfin یه حرف توی کادر رنگی نشون داده می‌شه
(`<div class="mark letter">`).

## آنلاین کردن

روی Cloudflare، به‌صورت یه Worker که فقط همین فایل‌ها رو سرو می‌کنه (`cloudflare/gryffin.jsonc`)، روی
`gryffin.uk` و `www.gryffin.uk`.

1. همون دو secret شکارچی باید در GitHub باشه: `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID`.
2. در GitHub برو به **Actions** ← **Deploy the Gryffin home page** ← **Run workflow**.

این workflow عمداً **فقط دستی** اجرا می‌شه، نه با هر push، که دامنه‌ی اصلی اتفاقی عوض نشه. اگه
`gryffin.uk` الان به جای دیگه‌ای اشاره کنه، Cloudflare دیپلوی رو رد می‌کنه و چیزی رو عوض نمی‌کنه؛
اول اون رکورد DNS رو بردار.

برای امتحان روی کامپیوتر خودت کافیه `index.html` رو باز کنی.

## بعداً: یک حساب و یک کیف‌پول برای همه

قدم بعدی (اختیاری) اینه که محصول‌ها یک ورود، یک درگاه پرداخت و یک پنل تأیید مشترک داشته باشن تا کارهای
اداری برای هر محصول جدا تکرار نشه. این صفحه به اون وابسته نیست و الان بدون اون کار می‌کنه.
